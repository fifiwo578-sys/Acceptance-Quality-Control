# Ethio-Djibouti Railway (EDR) | Acceptance & Quality Safety

## Production-Ready Acceptance & Quality Safety System

This production application provides an end-to-end monitoring, quality control, departmental task management, and automated daily reporting system for the Ethio-Djibouti Railway Share Company.

---

### Key Modules & Capabilities

1. **Dashboard & KPIs**:
   - High-contrast engineering dark UI (`#060a11` background, amber gold `#e8a308`, cyan, green, and red accents).
   - Real-time KPI statistics across all 10 operational sections.
   - Status matrices (Wagon, Locomotive, Coach x Pending, In Progress, Completed, On Hold).
   - Task breakdown by department (AQMS, Wagon, Locomotive, Coach, Equipment).

2. **Monitoring & Quality Control (10 Modules)**:
   - **Monitoring Incident**: Date, Train Number, Location (km), Train Captain, Accident Type.
   - **Monitoring Problem**: Date, Time, Loco No, Train No, Mileage, Captain ID, Captain Name, Monitoring Problems, Frequency.
   - **QC Wagon / Locomotive / Coach**: Equipment Number, Maintenance Type, Description, Fault, Spare Parts, Status, Dates, Remarks.
   - **Tasks**: AQMS, Wagon, Locomotive, Coach, Workshop Equipment.

3. **Daily Report System (Main Requirement)**:
   - **Aggregation**: Collects records for any selected date across all 10 modules automatically.
   - **13 Sections**: Executive Summary, Incidents, Problems, QC Wagon, QC Locomotive, QC Coach, AQMS Tasks, Wagon Tasks, Locomotive Tasks, Coach Tasks, Equipment Tasks, KPI Summary, and Remarks.
   - **Public Shareable Report Link**: Unique URL (`/reports/YYYY-MM-DD`) viewable in Public View Mode without exposing administrative controls.
   - **Publication & Confirmation**: Confirmation dialog, timestamped publication, and status transition from Draft to Published.
   - **PDF Generation & Print**: Built-in Android PrintManager / PDF engine to export, print, or save reports.

4. **Transactional Email & Notifications**:
   - **Resend API Integration**: Backend HTTP integration with `https://api.resend.com/emails`.
   - **Branded Email Template**: Ethio-Djibouti Railway branding, highlights, and direct public view button.
   - **Recipient Management**: Add, enable/disable, and remove recipient emails.
   - **Test Email**: Test notification delivery directly from the settings interface.
   - **Notification History**: Full audit trail of dispatched emails with status and timestamps.
   - **Daily Scheduled Notification**: Automatic notification schedule configured for `18:00` in `Africa/Addis_Ababa` timezone.

5. **Storage & Cloud Database**:
   - **Local Room Database**: Fast, offline-first SQLite database via Room with DAO flows and migrations.
   - **Supabase Cloud Sync**: REST sync endpoints for cloud backup and multi-user access.
   - **Archive Management**: Trash restoration, permanent deletion, and cancellation reinstatement with audit reasons.

### Setup Instructions

#### 1. Supabase Project
1. Create a project at [supabase.com](https://supabase.com).
2. Retrieve your **Project URL** (`https://<project-ref>.supabase.co`) and **anon public key**.
3. In the app, open **Email Notifications > Settings (gear icon)** or configure in environment secrets.

#### 2. Database Tables (SQL Schema for Supabase)
Run the following SQL in your Supabase SQL Editor:
```sql
CREATE TABLE IF NOT EXISTS reports (
    id BIGINT PRIMARY KEY,
    report_date TEXT NOT NULL,
    status TEXT NOT NULL,
    title TEXT NOT NULL,
    executive_summary TEXT,
    incidents_count INT DEFAULT 0,
    problems_count INT DEFAULT 0,
    qc_wagon_count INT DEFAULT 0,
    qc_loco_count INT DEFAULT 0,
    qc_coach_count INT DEFAULT 0,
    aqms_task_count INT DEFAULT 0,
    wagon_task_count INT DEFAULT 0,
    loco_task_count INT DEFAULT 0,
    coach_task_count INT DEFAULT 0,
    equipment_task_count INT DEFAULT 0,
    published_at TEXT,
    public_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS report_recipients (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email TEXT NOT NULL UNIQUE,
    name TEXT,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS report_notifications (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    report_id BIGINT,
    report_date TEXT,
    recipient_email TEXT,
    sent_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    status TEXT,
    error_message TEXT
);
```

#### 3. Environment Variables & Secrets
Configure via the Secrets panel in AI Studio or the app settings modal:
- `RESEND_API_KEY`: Your Resend API key (`re_...`).
- `REPORT_FROM_EMAIL`: Sender address (e.g. `reports@ethiodjiboutirailway.com` or verified domain).
- `APP_PUBLIC_URL`: Base domain for public report links (e.g. `https://edr-reports.railway.et`).
- `SUPABASE_URL`: Optional Supabase project REST URL.
- `SUPABASE_ANON_KEY`: Optional Supabase anon key.

#### 4. Resend / Email Configuration
1. Register at [resend.com](https://resend.com) and create an API key.
2. In the app, go to **Reporting > Email Notifications > Settings**, paste your `RESEND_API_KEY`, and set your verified sender email.
3. Tap **Send Test Email** to verify delivery.

#### 5. Admin Account & Roles
- Tap the **ADMIN / PUBLIC** pill in the top app bar to toggle between Administrator mode (full data entry, report publication, email dispatch) and Public View mode (read-only document view).

#### 6. Public Report URL
- Published reports generate a shareable link in the format: `https://edr-reports.railway.et/reports/{YYYY-MM-DD}`.
- Tap **Copy Link** or **Open Link** on any published report.

#### 7. How to Create, Publish, and Send a Daily Report
1. Open **Daily Reports** in the sidebar navigation.
2. Tap **Compile Today's Report** (or choose another date). The system gathers all incidents, problems, QC inspections, and tasks for that date.
3. Review the 13-section report.
4. Tap **Publish** and confirm the dialog. The status changes to **Published** and the public URL is generated.
5. Tap **Send Email** to dispatch the notification to all active recipients.
